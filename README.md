# Agus Entrena

Sitio web estatico para presentar las rutinas y el proyecto de Agus.

## Estructura
- `index.html`: pagina principal.
- `pages/`: paginas secundarias.
- `css/main.css`: punto de entrada de estilos.
- `css/base/`: estilos base.
- `css/layout/`: encabezado y pie de pagina.
- `css/components/`: botones y tarjetas.
- `css/pages/`: estilos especificos de paginas.
- `js/main.js`: punto de entrada de JavaScript.
- `js/components/`: componentes interactivos.
- `js/pages/`: comportamiento por pagina.
- `assets/images/`: imagenes del proyecto.

## Publicacion
Se puede publicar con GitHub Pages usando la rama `main` y la carpeta raiz `/`.
